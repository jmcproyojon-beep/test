# Purbachal house promo — build scripts

Reproducible build for the branded property promo cut from a customer-supplied
walkthrough plus two exterior photos.

## Inputs (not in git)

Client media lives under `projects/purbachal-house/`, which is gitignored
because it is large and regenerable from the originals:

```
projects/purbachal-house/
├── assets/video/source.mp4      # customer WhatsApp walkthrough, 478x850, 60fps, 1:03
├── assets/images/photo-01.jpg   # exterior, three-quarter view
├── assets/images/photo-02.jpg   # exterior, frontal view from the lawn
├── assets/overlays/             # generated by the scripts below
└── renders/purbachal-house-promo.mp4
```

## Run order

```bash
python3 -I client-builds/purbachal-house/make_overlays.py   # Bengali lower thirds + brand bar
python3 -I client-builds/purbachal-house/make_cards.py      # title overlay + end card
python3 -I client-builds/purbachal-house/build_promo.py     # trim, stabilise, overlay every beat
python3 -I client-builds/purbachal-house/fix_stills.py      # rebuild the still beats only
python3 -I client-builds/purbachal-house/artifacts_purbachal.py
```

Then stitch the beats with 0.35s `xfade` dissolves, mux the cleaned ambience bed
and write `renders/purbachal-house-promo.mp4` (1080x1920, 30 fps).

## Requirements

- `ffmpeg` with `vidstab` (two-pass stabilisation) and `libfreetype`
- `fonts-noto-core` for Bengali (`NotoSerifBengali-Bold`, `NotoSansBengali-Regular`)
- Python: `pillow` (built with raqm — Bengali needs shaping), `numpy`, `jsonschema`

## Gotchas worth keeping

- **`zoompan` multiplies frames.** `-loop 1 -t N -i image` caps the *input*, not the
  output: zoompan then emits `d` frames per input frame and the clip runs for
  minutes. Cap the output with `-frames:v`.
- **Fading a single-frame overlay makes it vanish.** A PNG read without `-loop 1`
  is one frame at t=0; `fade=...:alpha=1` starting later leaves that frame fully
  transparent and `overlay` repeats it. Loop the overlay input **and** bound it
  with `-t`, or the filtergraph never ends.
- Captions state only what is visible on screen. No floor area, room count or
  price was supplied by the client, so none appears in the video.
