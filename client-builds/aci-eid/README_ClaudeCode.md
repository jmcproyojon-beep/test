# ACI Eid Reel (৬০ সেকেন্ড) — Claude Code দিয়ে এডিট করার নির্দেশনা

## গল্প এক লাইনে
ঈদের আগের রাতে অফিসে ক্লান্ত ছেলে → ACI Lemon খেয়ে চাঙা হয়ে কাজ শেষ করে বাড়ির পথে → ভোরে মায়ের দরজায় → ঈদের সকালে রান্নায় ক্লান্ত মায়ের হাতে ACI Orange → মা-ছেলে একসঙ্গে রান্না → পুরো পরিবার এক টেবিলে, শেষে দুই বোতলের প্যাকশট।

## এই ফোল্ডারে যা আছে
- `song_60s.mp3` — আপনার গানের ০:২৫–১:২৫ অংশ, শুরু-শেষে fade সহ
- `make_reel.py` — ক্লিপ কাটা, জোড়া, গান বসানো আর শেষের লেখা — সব এক কমান্ডে
- `clips/` — এখানে Flow থেকে নামানো ৭টি ক্লিপ রাখবেন

## ধাপ ১: Flow থেকে ক্লিপ নামানো

## ধাপ ২: Claude Code-এ এই ফোল্ডার খুলে এই প্রম্পট দিন
```
এই ফোল্ডারে make_reel.py আছে। ffmpeg ইনস্টল আছে কি না দেখো (না থাকলে ইনস্টল করো),
clips/ ফোল্ডারে ৭টি ফাইল ঠিক নামে আছে কি না মিলিয়ে দেখো, তারপর `python3 make_reel.py` চালাও।
শেষে ACI_Eid_Reel_60s.mp4 থেকে ০, ১৫, ৩৫ আর ৫৮ সেকেন্ডের ফ্রেম বের করে দেখাও যাতে আমি যাচাই করতে পারি।
```

## ধাপ ৩: পরিবর্তন করতে চাইলে Claude Code-কে যা বলবেন
সব পরিবর্তন `make_reel.py`-এর উপরের `EDL` তালিকায় হয় — প্রতিটি লাইন = (ফাইল, সোর্সের কত সেকেন্ড থেকে, কত সেকেন্ড)।
- "০২ নম্বর ক্লিপ ১ সেকেন্ড আগে থেকে শুরু করো, ০৫ নম্বর ১ সেকেন্ড ছোট করো, মোট ৬০ সেকেন্ড রাখো।"
- "শেষের লেখা বদলে ক্লায়েন্টের ট্যাগলাইন '…' বসাও" → `END_TEXT` বদলায়।
- "বাংলা ফন্টে লেখা দাও" → `FONT`-এ একটা বাংলা .ttf ফন্টের পাথ দিন (যেমন Noto Sans Bengali)।
- "ক্লিপগুলোর মাঝে ০.৩ সেকেন্ডের crossfade দাও" → concat-এর বদলে xfade ব্যবহার করতে বলুন।
- "গানের অন্য অংশ নাও, ০:৩০ থেকে" → মূল mp3 দিয়ে `song_60s.mp3` আবার কাটতে বলুন:
  `ffmpeg -ss 30 -t 60 -i <মূল গান>.mp3 -af "afade=t=in:d=0.8,afade=t=out:st=57:d=3" song_60s.mp3`
- "1080x1920 এক্সপোর্ট করো" → `W, H`-এ 1080, 1920 দিন (360p সোর্স হলে Flow-এ আগে আপস্কেল করাই ভালো)।

## টাইমিং যেভাবে বসানো (গানের সঙ্গে)
- ০:০০–০:১৫ রিল = গানের শান্ত verse → ক্লান্তি, স্লো-মোশন
- ০:১৫ নাগাদ বোতল খোলা → গানের pre-chorus এ উঠে আসা ("ফিরবো বাড়ি খুশি নিয়ে")
- ০:২৫ এর পর বাড়ি ফেরা → chorus "উড়ে উড়ে যায়"
- ০:৫০–১:০০ পরিবার ও প্যাকশট, শেষ ৪ সেকেন্ডে লেখা, শেষ ১ সেকেন্ডে fade
বিট পুরোপুরি মেলাতে Claude Code-কে বলুন: "গানের বিট শনাক্ত করে কাটগুলো সবচেয়ে কাছের বিটে সরাও, মোট দৈর্ঘ্য ৬০ সেকেন্ড রেখে।"
