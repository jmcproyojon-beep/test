# Ukulele clips

Five clips the client sent on 2026-10-24 to keep on hand. Not tied to any
property listing — stored here because `projects/` is gitignored and this
container is ephemeral, so anything meant to survive has to be committed.

They were uploaded twice in the same session; both uploads are byte-identical,
so there is only one set.

## Contents

All five: 640x360, 24fps, 10.005s, H.264 + AAC. `contact-sheet.jpg` shows a
frame every 2s from each.

| File | Shot |
|---|---|
| `01-player-portrait.mp4` | Mid shot of the player, then a lit profile portrait against the dark background |
| `02-fretboard-closeup.mp4` | Tight on the fretboard and fretting hand travelling up the neck |
| `03-soundhole-strumming.mp4` | Close on the soundhole and strumming hand; warmest look of the five |
| `04-player-brick-wall.mp4` | Mid shot against a brick wall, cutting to a close portrait |
| `05-player-wide-environment.mp4` | Widest framing — player in the room, most background visible |

Shared look: low-key, single-source lighting, dark surround, warm wood against
a patterned dark shirt. They cut together as one set.

Each clip carries its own audio (ukulele, roughly -20 to -22 dB mean), so a
montage can run the source audio instead of a music bed.

## If these get edited together

The house promo scripts under `client-builds/` are 1080x1920 portrait and
assume vertical phone footage. These are 640x360 landscape at a quarter of that
height, so they need their own treatment — upscaling 360p to a 1920-tall frame
will look soft. A 16:9 cut at 1280x720, or a square/4:5 crop, suits them better.
