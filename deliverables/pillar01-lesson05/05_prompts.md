## শিক্ষার্থী · Photosynthesis

**Prompt:**

```
তুমি একজন অভিজ্ঞ বাংলা মাধ্যমের বিজ্ঞান শিক্ষক। আমি অষ্টম শ্রেণির শিক্ষার্থী। Photosynthesis বিষয়টি একদম সহজ বাংলায় বুঝিয়ে দাও। বাংলাদেশের পরিচিত গাছপালা ব্যবহার করে তিনটি বাস্তব উদাহরণ দাও। একটি সহজ ধাপভিত্তিক ব্যাখ্যা এবং শেষে পাঁচটি অনুশীলনী প্রশ্ন দাও।
```

**Follow-up:**

```
এবার বিষয়টি আরও সহজভাবে একটি গল্পের মাধ্যমে বোঝাও এবং আমাকে একটি করে প্রশ্ন করে আমার উত্তর যাচাই করো।
```

## অফিস · মিটিং নোট → Action Plan

**Prompt:**

```
তুমি একজন দক্ষ অফিস অ্যাসিস্ট্যান্ট। নিচের মিটিং নোটগুলো থেকে একটি প্রফেশনাল Action Plan তৈরি করো। প্রতিটি কাজের জন্য Task, Priority, Responsible Person (যদি জানা না থাকে Unassigned), Deadline (শুধু জানা থাকলে), এবং Next Step দেখাও। কোনো তথ্য অনুমান করে তৈরি করবে না।

Meeting Notes:
Monday meeting: website banner needs update, customer FAQ unfinished, product images need review, marketing report required by Friday, team must check final designs.
```

**Follow-up:**

```
এই কাজগুলোকে High, Medium এবং Low Priority অনুযায়ী সাজাও এবং যেসব তথ্য অনুপস্থিত সেগুলো আলাদা করে দেখাও।
```

## ইমেইল · শক্তিশালী প্রম্পট

**Prompt:**

```
তুমি একজন প্রফেশনাল কর্পোরেট কমিউনিকেশন অ্যাসিস্ট্যান্ট। আমার টিম মিটিং বৃহস্পতিবার সকাল ১০টায় নির্ধারিত ছিল। জরুরি অফিস কাজের কারণে মিটিংটি বৃহস্পতিবার বিকেল ৩টায় পরিবর্তনের অনুরোধ জানিয়ে ম্যানেজারের কাছে একটি ভদ্র, সংক্ষিপ্ত বাংলা ইমেইল লিখে দাও। Subject, Greeting, Main Message এবং Professional Closing অন্তর্ভুক্ত করো।
```

**Follow-up:**

```
ইমেইলটি আরও সংক্ষিপ্ত এবং বিনয়ী করে লেখো।
```

## ব্যবসা · ৭ দিনের ফেসবুক ক্যালেন্ডার

**Prompt:**

```
তুমি একজন বাংলাদেশি Digital Marketing Strategist। ঢাকার একটি ছোট পোশাকের দোকানের জন্য সাত দিনের বাংলা Facebook Content Calendar তৈরি করো।

Business: Cotton T-shirt shop
Audience: Students and young professionals
Goal: Increase engagement and genuine product inquiries

প্রতিদিনের জন্য দাও:
1. Post Topic
2. Hook
3. Bangla Caption
4. Visual Idea
5. Call to Action
6. Suggested Format
7. Three relevant hashtags

কোনো অযাচাইকৃত দাম, ডিসকাউন্ট, পণ্যের বৈশিষ্ট্য বা অফার তৈরি করবে না।
```

**Follow-up:**

```
Day 01-এর পোস্টটি আরও আকর্ষণীয় করো এবং একটি 20-second Reel Script তৈরি করো।
```

## ক্রিয়েটর · ভিডিও আইডিয়া → স্ক্রিপ্ট

**Prompt:**

```
তুমি একজন অভিজ্ঞ বাংলাদেশি Educational Content Strategist। AI শেখার বিষয়ে নতুনদের জন্য পাঁচটি আকর্ষণীয় Short Video Idea তৈরি করো।

প্রতিটির জন্য:
- Topic
- Audience Problem
- First 3-second Hook
- Main Teaching Points
- Visual Demonstration
- 30-second Bangla Voiceover
- CTA

ভাষা সহজ ও স্বাভাবিক রাখবে। অতিরঞ্জিত দাবি করবে না।
```

**Follow-up:**

```
প্রথম আইডিয়াটিকে একটি 60-second beginner-friendly Bangla explainer video script-এ রূপান্তর করো। প্রতিটি scene-এর সময়, narration, screen recording instruction এবং on-screen text দাও।
```

## রিসার্চ · সারাংশ + উৎস-বাক্য

**Prompt:**

```
নিচের লেখাটি পড়ে সহজ বাংলায় সারাংশ তৈরি করো। প্রথমে পাঁচটি মূল বিষয়, এরপর তিনটি গুরুত্বপূর্ণ সিদ্ধান্ত বা পর্যবেক্ষণ, এবং শেষে দুইটি Follow-up Question দাও। মূল লেখায় নেই এমন তথ্য যুক্ত করবে না।

কাল্পনিক প্রতিবেদন — 'আলোঘর' কমিউনিটি লাইব্রেরি, মিরপুর, ঢাকা (২০২৬)
এই বছর লাইব্রেরির নিবন্ধিত সদস্য ৮২০ জন থেকে বেড়ে ১,১৫০ জন হয়েছে। সবচেয়ে বেশি বেড়েছে স্কুল ও কলেজের শিক্ষার্থী সদস্য। শুক্রবারের শিশুদের গল্প পড়ার আসরে গড়ে ৪০ জন অংশ নিয়েছে। তবে সন্ধ্যার পর পড়ার কক্ষে আলো কম থাকায় অনেক সদস্য অভিযোগ করেছেন। নতুন বই কেনার বাজেটের প্রায় অর্ধেক খরচ হয়েছে বিজ্ঞান ও প্রযুক্তির বইয়ে। স্বেচ্ছাসেবকের সংখ্যা ১২ জন থেকে কমে ৭ জন হয়েছে, ফলে শনিবার লাইব্রেরি দুই ঘণ্টা আগে বন্ধ করতে হয়েছে। কমিটি আগামী বছর ডিজিটাল ক্যাটালগ চালু এবং পড়ার কক্ষে নতুন আলো লাগানোর পরিকল্পনা করেছে।
```

**Follow-up:**

```
সারাংশের প্রতিটি গুরুত্বপূর্ণ দাবির পাশে মূল লেখার কোন বাক্য সেটিকে সমর্থন করে তা দেখাও।
```

## পরিকল্পনা · বিকেলের রুটিন

**Prompt:**

```
তুমি একজন Productivity Coach। আমার আজ বিকেল ৪টা থেকে রাত ৯টা পর্যন্ত সময়ের জন্য একটি বাস্তবসম্মত পড়াশোনা ও কাজের রুটিন তৈরি করো।

Tasks:
Study — 2 hours
Assignment — 1 hour
Reading — 30 minutes
Family time — 1 hour

মাঝে উপযুক্ত বিরতি রাখবে। প্রতিটি কাজের Start Time, End Time এবং Priority দেখাবে। মোট সময় পাঁচ ঘণ্টার বেশি হবে না।
```

## পূর্ণ ওয়ার্কফ্লো · স্টেশনারি দোকান

**Prompt:**

```
তুমি একজন বাংলাদেশি Small Business Content Assistant। আমার কাল্পনিক ব্যবসার তথ্য থেকে একটি ছোট কনটেন্ট প্যাকেজ তৈরি করো।

Business: Dhaka stationery shop
Audience: School and college students
Goal: Inform customers about available stationery categories

Deliver:
1. Three social media content ideas
2. One complete Bangla Facebook caption
3. One image design brief
4. One 30-second educational Reel Script
5. One customer FAQ draft
6. A verification checklist for information that must be confirmed before publishing

Do not invent prices, discounts, inventory levels or guarantees.
```
